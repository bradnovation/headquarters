# vault/ - the quarantine for third-party words

*This README is the one file in this directory that version control is
allowed to see. Everything else here is ignored by `.gitignore`, on purpose,
before this repository is ever cloned for the first time - see the
comment above the `vault/*` rule there.*

---

## What lives here

Raw material that is not this organization's own words: call recordings,
transcripts, forwarded correspondence, anything a real counterparty, client,
colleague, or friend said in their own voice. `doctrine/CONSTITUTION-CORE.md`
classifies this as C3, the strictest class this repository recognizes.

## The rule

**Version control does not see this directory's contents. No remote ever
receives them. And nothing running without a human present is handed them to
read.** Not a summary, not an excerpt, not a single quoted sentence carried
out of it without the minimizing step described below. A public repository's history is permanent; what enters
version control stays there forever, which is exactly why this directory
exists - so the material that must never leave your own machine has an
obvious, structural place to live where it cannot accidentally travel with
everything else.

Only the seat this organization designates as steward of sensitive material
touches this directory's contents (in the default roster, the Chief of
Staff - see `org/seats/chief-of-staff/CHARTER.md`), and only in a live,
operator-present session - never on a schedule, never inside a fan-out fleet,
never inside a dream run. If a scheduled or unattended routine of any kind
would need to read this directory to do its job, that routine is designed
wrong; redesign it rather than granting the exception.

## What may leave, and in what form

Nothing raw ever leaves. What is allowed to leave is *derived work*: an
index card under `transcripts/index/` that points at what a raw file
contains without reproducing it. A good index card names the date, the
subject, the gist, and enough of an anchor that a human could find the
original again - and minimizes the other party's exact words to the smallest
quotation an anchor actually needs, never a full transcript with names
swapped out. See `transcripts/index/README.md` for the card format.

## Why the empty directory still matters

This directory exists, tracked, with this README as its only tracked file,
before you ever run the onboarding interview. The quarantine is a structural
fact about the repository, not a step you configure later - a product that
asks its first onboarding question before this boundary exists is a product
that has already made the C3 mistake possible by default.
