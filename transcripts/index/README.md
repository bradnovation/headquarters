# transcripts/index/ - derived cards, never raw material

*Everything in this directory is tracked and committed. If a file here would
expose a third party's own words beyond a minimal anchor quotation, it does
not belong here - it belongs in `vault/`, or it should not exist yet.*

---

## What an index card is

A short, committed record that points at something a raw file in `vault/`
contains, without reproducing that raw file. One card per source item is the
usual shape. A card exists so a later session, or a stranger who has never
seen the raw material, can know that a conversation, a document, or a
recording exists, roughly what it covers, and where to find the original -
without ever reading the original's exact words.

## What a card contains

- **When** the source material is from.
- **What it's about**, in this organization's own words - a paraphrase, not a
  transcript excerpt.
- **The anchor** - the smallest quotation, if any, that a human would need to
  confirm they have found the right source. Smallest, not most complete.
- **Where the raw material lives**, so a human with the right access can go
  find it - never a path assumption that it is readable from this repository.

## What a card is not

- Not a transcript with names removed. Removing a name does not change
  whether the words are still substantially a third party's own; the test is
  whether what is written down is *this organization's* account of the
  material or *the other party's exact words* carried forward. Only the
  former belongs here.
- Not a place to paste something "just this once" because writing the proper
  card takes longer. The discipline exists precisely for the file that feels
  like an exception.

## The rule this directory exists to serve

`vault/` holds what must never be committed (C3, see `vault/README.md`). This
directory holds the only thing allowed to graduate out of it: derived,
minimized, committed-safe cards. If it is ever unclear whether something
belongs here or in `vault/`, it belongs in `vault/` until someone deliberately
writes the minimized card - never the other way around.
