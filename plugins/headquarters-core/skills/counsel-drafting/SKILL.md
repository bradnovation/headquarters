# Counsel drafting flow

Full governing procedure: the org's General Counsel charter. Run this
whenever a mission needs a contract-shaped deliverable, or a task carries
money or liability weight.

1. **Convene General Counsel at reasoning tier** (the org's model-tier
   configuration, duty `general-counsel-drafting`) for any judgment call:
   fees, scope boundaries, liability caps, termination conditions, or any
   precedent-flywheel decision. Only drop to building tier for pure assembly
   once every judgment call is already settled (populating a template with
   known facts, reproducing a precedent entry verbatim) — never for a
   drafting decision on its own.
2. **Precedent first, template second.** Before drafting a clause from the
   templates library, check the precedent library for a prior ruled
   term-set that already answers it. The precedent library only has real
   entries once a real engagement has executed and been ruled on; an empty
   precedent library for a given lane is the honest v1 state, not a bug.
3. Draft using the templates library (pilot agreement, scope of work,
   engagement letter, NDA) as the skeleton.
4. **Every output file opens with the standing header, verbatim, before any
   other content:**
   ```
   DRAFT ONLY. Prepared by General Counsel (AI). Not legal advice. Human
   legal review recommended before execution.
   ```
   Where the draft carries material money or liability (fees, liability
   caps, IP assignment, termination triggers — the normal content of this
   function's output), add immediately after: **RECOMMEND HUMAN LEGAL
   REVIEW**. This is not a drafting judgment call; when in doubt whether
   content counts as material, the flag goes in.
5. **This function is permanently propose-only, structurally, not by policy
   prose.** There is no send path to build toward and no future amendment
   adds one. The draft lands in a mission directory or directly in the
   operator's hands; nothing this function produces is ever countersigned,
   filed, or transmitted by an agent.
6. Route the draft through the org's canon-guard seal check before it is
   considered done, even though clause language itself sits outside canon's
   voice rules (cover notes and guidance italics still carry the org's voice
   discipline).
7. **When the operator negotiates and rules on a real engagement's terms**,
   append the ruled term-set to the precedent library and log it to the
   precedent ledger, in the same shared ledger format as every other ledger.
   A term counts as "ruled" only once negotiated with an actual counterparty
   on an actual engagement and either executed or finally settled (a firmly
   rejected term is also precedent) — never fabricate a precedent to seed
   the library early.
