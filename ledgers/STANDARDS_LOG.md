# STANDARDS_LOG - standards-guard's verdict log
<!-- file-class: PERSONAL -->

Append-only. One row per deliverable checked: date, deliverable path (or
mission identifier), seat of origin, and each rule's verdict and severity. A
guard error appends its own row, shaped distinctly from a content verdict, so
it is never mistaken for one (`org/functions/standards-guard/CHARTER.md`).

No entries yet. This ledger stays empty and honest until standards-guard
checks its first deliverable.
